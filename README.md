# 📚 Sistema de Gerenciamento de Biblioteca

Bem-vindo ao **Sistema de Biblioteca**! Este projeto tem como objetivo facilitar o gerenciamento de empréstimos de livros em uma instituição, permitindo o controle completo de alunos, livros e empréstimos.

---

## 🚀 Tecnologias Utilizadas

- ⚙️ **Java 17**  
- 🌱 **Spring Boot**  
- 🎨 **Thymeleaf**  
- 🐘 **PostgreSQL**  
- 🛠️ **Maven**  

---

## 🧩 Funcionalidades

- ✅ CRUD de **Livros**
- ✅ CRUD de **Alunos**
- ✅ CRUD de **Empréstimos**
- 🔍 Visualização de status dos empréstimos
- 📆 Controle de datas de empréstimo e devolução
- 🚨 Indicação de empréstimos atrasados
